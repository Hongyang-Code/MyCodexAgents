# 按用途获取与使用信息

这是未部署研究版的信息契约，不增加采集权限。先写本轮决策问题、对象、截止时间、缺口、优先级、可改变的判断和停止条件，再查询公开或已授权来源。未知账户信息不妨碍非个性化研究。没有具体用途的资讯不加入默认抓取清单。

## 需求与降级

| 优先级 / 用途 | 最少信息及核查 | 缺失时处理 |
| --- | --- | --- |
| P0 估值与结算 | 完整代码/份额/币种；官方净值归属日、当前版本、实际获取和审阅时间；目标日历 | 不猜今日净值，不结算缺证据的预测；保留 pending |
| P0 行动前置 | 具体渠道与有效期的费率、申赎开放/限购、确认/到账、分红/拆分、批次持有期；真实现金与风险限制 | 不输出可执行金额；缺历史证据只能另走已冻结条件研究，不能补写确认值 |
| P1 事件相关性 | 首次公告及修订；基金实际披露暴露、披露日与归属期、覆盖范围和变化风险 | 暴露未知只列背景，不据基金名称或跟踪指数认定当前持仓；联接基金穿透不得重复计权 |
| P1 预期差 | 同一指标/期间/单位/调整口径/统计量的发布前预期快照和首次实际发布 | 任一缺失填 unknown；不能以事后评论或后续修订值替代原预期/首次值 |
| P2 解释与候选 | 政策、利率、信用、汇率、行业事件与暴露之间的传导链，支持及反对证据 | 保留方向/时滞/抵消因素为假设；无充分证据不写成因果或上涨概率 |

P0 是受影响动作的必要条件，并不要求为无关研究收集全部账户资料。P1 只为确有相关暴露或待核验假设获取。P2 先去重、归并同事件，再按预算读取；达到本轮明确预算或已有足够事实回答问题即停止。转载数量和多角色意见一致不能增加独立证据数。先查直接公告/数据发布者；媒体可提供线索，观点单独归属作者。相互矛盾的来源保留冲突，不能靠多数投票消除。

## 时间、版本与事实身份

净值首次可得时间未知时保留 null；不能用净值日、网页日期或第一次本系统抓取推断市场首次可得。`market.NavRecord` 的生产过滤保持原样。回顾性假设只存在独立 retrospective 视图，不回填已核实时刻。

事件记录分开 `event_at`、`first_published_at`、`version_published_at`、`revised_at`、`first_available_at`、`retrieved_at`、`reviewed_at`。事件发生可早于报道，也可指已公告的未来日程，不把它当可知时间。当前版本修订需要 `supersedes` 指向旧证据，不覆盖旧内容。原始字节、来源URL、哈希、版本和使用许可在私有存储保留。时间未知填 null；首次可得声明须另附可审阅档案引用。

事实、作者观点与本系统假设分别标记。所谓 fact 是调用者审阅后的证据分类，schema 本身不证明真实性。宏观发布变化不自动等于价格冲击：市场预期口径、暴露大小、久期/信用、汇率对冲、市场已反应程度可能未知。LLM 只可抽取/提出可证伪解释，不填造缺失数值，不把语气、置信度或投票换算为概率。

## 可测试接口与尚未接通部分

`fundpilot.information.Evidence` 为本地不可变记录；字段见同名 dataclass，subject 使用完整基金/份额/渠道键。宏观序列使用独立明确标识，连接到基金时另保存暴露证据。`known_at=max(retrieved_at, reviewed_at)`；可见还要求 reviewed 严格为 true 且未超过事先规定的 valid_until。有效期须按用途/产品规则审阅，程序不猜统一期限。

`assess(purpose, subject, records, cutoff)` 支持 valuation、event_analysis、action_research；只接受对应对象、已知且未过期的事实，返回缺项和 abstain 或 evidence_ready_for_review。修订替代旧证据，重复ID拒绝；调用者标注 conflicted 的主题在消解前保持缺证据状态，程序不会自动发现所有事实冲突。已审阅且截止前已知的冲突即使过期也持续阻断该对象/主题；supersedes 只表示版本替代，不证明冲突已解决。当前 schema 没有经审阅的消解事件，保守阻断且不自动解除。调用者必须持续传入完整证据历史，不能删去冲突记录来恢复就绪；本地函数不提供跨调用持久化。未来才可知或其他对象的冲突不提前影响本次用途。返回始终 `action_authorized=false`、`probability=null`；它是附加研究检查，不能替代持仓、风险和交易闸门。

`release_surprise(...)` 仅在预期已于首次发布前被系统获取和审阅，且两个值的五项定义完全一致时计算实际减预期。预期数字的事实身份表示“该来源当时报告该预期”，不表示预期可靠。修订后实际值、意见、无预期或不可比口径返回 unknown。结果不是收益预测，也不证明事件导致价格变化。

当前模块只做本地契约校验与差值计算，无网页抓取、外部代码执行或自动建议入口；尚未接入 DailyRunner 生产适配器，也未自动核验原字节/授权/来源真实性。上游必须实际核对原文与引用，不得为通过门槛构造声明。公开源访问仍须遵守许可、限流与当前网络授权；新凭据、付费服务和账户权限不在本次范围。

## 机制卡、依赖失效与失败处理

每份机制卡明确完整代码及 A/C、渠道、规则生效起止与证据版本；净值归属日和实际公布分开；列申赎截止、申请计价、确认、可用资金日及尚未到账状态。费用逐项注明已含 NAV 或外扣，不能重复扣除。卡内未知项仅阻止依赖它的结论，无关研究仍可继续。

暴露卡列报告期、实际披露日、覆盖率及未知部分。前十大不代表完整或实时持仓；不能补齐未知权重至100%，也不能按已知部分归一后冒称全组合。不得用后来披露的持仓回填较早决策；联接、母子基金与底层资产分层保存并明确穿透口径，防止双计。无覆盖证据时只给局部解释。

新证据推翻费用、身份或数据口径时，对所有依赖它的收益、排名、解释和摘要同步撤销可用结果，保留旧版本与失效原因，不只添加末尾警告。`invalidate_derived(nodes)` 对调用者明确给出的依赖图传播 missing/stale/conflict/rejected，将失效输出 value 置 null；valid 的数值0保留。图缺依赖按 missing 处理，循环拒绝。该函数不推断未声明的依赖，尚未自动接入历史研究输出；旧审计包不得覆写，应追加失效回执并重新冻结复算。

证据不足对应 abstain，不能解释为已有证据支持持有不变。仅有充分证据且通过独立风险审查的“不操作”才能记录为有依据的决定；两者都不授权交易。

网络瞬时错误与确定性校验失败分开。`retry_decision` 是纯策略函数：只读瞬时错误在显式总尝试预算内可重试；校验或权限失败直接降级，预算耗尽也降级。结果未知或涉及写入先 reconcile，不能自动重复记账。调用者设置超时、退避及预算并保留原幂等ID；本模块不发网络请求、不执行重试、不更改权限。依赖关键失败的结论必须弃权，不能将降级写作成功。
