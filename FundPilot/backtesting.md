# 历史回放与验证边界

固定 1、5、20 个已核实交易日的预测期限，不能用自然日或跳过缺失日替代。每条观察记录发布和实际可获取时间，修订须新版本。在预测截止点过滤不可获取数据，冻结模型/参数/预测，再读取结果。

现实现 no_direction（弃权）、persistence（价格水平不变）与固定 trend 基线、逐点回放、已到期目标日结算及诊断指标。它们仅是比较基线，不代表训练出的超额收益模型，也不是 LLM Agent 效果测试。输入必须为可比总回报水平，未处理现金分红的原始净值不能冒充总回报。当前公开历史抓取缺少完整历史发布时间与分红证据，不能直接产生严格历史样本外盈利结论。

训练、验证、测试按时间划分，并剔除标签区间跨越边界的训练/验证样本；不得随机打乱时间序列。独立最终测试集不反复调参。报告整个候选模型家族和失败实验，控制多重检验、重叠标签及幸存者偏差。

LLM 即使只收到旧新闻，也可能在训练中见过后续结果。历史 LLM 分析须标为事后研究；已见结果的旧窗保留 reused_development，不能因裁剪材料而称盲测或独立 OOS。LLM 主体的效果须单独验证，未来样例先冻结证据与判断、到期评分；研究记录不等于正式定时或实盘授权。

真正交易回测还须按历史有效规则模拟未知价申请、15点等具体渠道截止（不默认）、申购确认、赎回应收/到账、限购、分红及费用。需与长期持有、封闭资金池定期投入、固定比例再平衡及适用指数比较，不能给基准额外钱。预测 MAE/方向/Brier 不是这些策略的可实现净收益。

目前基线预测、统计原语及显式事件驱动成本模拟内核已测试；后者重放经核实的申请、计价、确认、到账、分红事件，不生成策略订单。完整策略决策、逐批持有期费率/取整与实盘样本外效果尚未验收。没有证据时允许“未证明有效”，不能以最近半年拟合漂亮为由进入正式策略。


## 最小 LLM 研究验证协议

使用当前 dot 已提供的真实 LLM 能力，检索并核对截至固定截点可用的新闻、政策、市场与基金材料，形成可反驳的1/5/20估值日研究判断。估值日历与目标日期须明确核实，不能冒用自然日或申赎开放日。确定性程序执行时间资格、数值、冻结和成熟评分；trend20/persistence只作基线，mock只测工程，不代表真实LLM输出。不新增训练管线、模型服务、多角色框架、SDK、API密钥或付费。

每张卡冻结：唯一ID、对象及份额、固定证据截点、真实生成/冻结时刻、期限与目标估值日、方向判定口径、无条件方向（涨/平/跌或弃权）、引用证据、反证、条件情景及其可核验触发条件和失效条件、缺口与弃权理由，以及实际可知的模型/提示版本。未知元数据如实标 unknown；不得倒填冻结时刻或把截点以后取得的信息冒充截点前已知。主观强弱不等于校准概率。

无条件方向与条件情景分别评估。情景及触发规则事前冻结，未触发、无法判定触发与失效都留记录，禁止未来挑选命中情景作为整体预测正确。全部预登记卡均保留：同时报告预测覆盖率、弃权率、已成熟非弃权卡的方向命中率及各分母；未成熟、缺实际观察和无法评分单列，不混入命中或失败。基线与LLM尽量同对象、同期限、同信息资格比较，不可比样本披露。

已见历史结果仅用于复盘，保留 reused_development；LLM参数记忆风险不能靠裁剪检索材料消除，不能声称盲测或独立OOS。未来卡先冻结、到期后追加评分与反例；没有未来结果就只报告待成熟。此协议只形成研究记录，不将判断转成买卖/仓位指令，不启用正式定时或实盘；真实卡与来源仅私有保存。

新增批次可按llm-loop.md的research_numeric_v1独立冻结主观未校准p_up及q10/q50/q90。交易/方向弃权不自动取消数值研究；成熟后复用Brier并计算pinball、覆盖及宽度，固定同样本常数基线，缺预测/标签不计零损失。此为测量能力，不是盈利或校准改善；旧卡不回填，候选预算不重置。
