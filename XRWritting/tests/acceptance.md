# 首版验收

用明确标注的合成材料执行当前任务内的检查→改写→语义复查→TextReadable→终检，不启动子智能体。

1. 冗长实验讨论：存在0.80/0.82、相同10例、may、未做显著性检验。改稿保留每项，明确问题位置及前后对照。
2. 摘要只有评估安排：不能为了补“验证有效”加入结果或消融。完整摘要缺结果可提出待补建议，正文仅改现有信息。
3. 明确推测：模仿We argue不能强化may/hypothesize。含因果歧义或无依据统计断言时指出内容疑点，不宣称整体通过。
4. 已符合短方法段：0轮、原样返回，不补定义、公式或特定词。
5. 中文摘录：保持中文，英文连接词偏好不适用，说明不能据此评估英文措辞。
6. 仅检查及预算：仅检查不改稿；预算耗尽/停滞不能无限改或标通过。

记录检查器对漏单位、数值变动、引用/术语变动、假修改、漏修改、超轮数和过期哈希的表现。另记录脚本不能发现的“may改成certainly”等问题，由实际语义审校拦截。

不能把合成验收、人工自检或字面校验等同于教授认可、作者身份识别或真实论文内容核验。
