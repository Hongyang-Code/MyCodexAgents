# 阶段2：设计与候选

科学结构先冻结。读取参考图的构图、主次、留白、比例、字体、语义色、图像、立体对象和箭头，不借用其科学步骤。没有参考时使用克制的论文视觉语言；需要检索且宿主可联网时找可追溯论文/作者图，记录实际查看位置，无法联网仍可用原生候选设计。

写style_guide：背景、语义角色的填充/边线/文字色、字体及印刷字号、边类型、线宽、圆角和间距。可覆盖所有默认值；不能按输入编号随意上色。强调贡献，辅助步骤减弱。立体张量用原生cube或成组多面对象，普通计算用模块，矩阵序列等按实际语义表达，不能全图都是立方体。

新建可以运行 plan 生成两种完整规划，再 build 两个完整.drawio并原生渲染，自评后选择；工具分数只衡量几何，不决定美观。实际有布局草图时优先照用户布局，自行生成内部boxes，不强行采用自动分层结果。局部编辑跳过整图候选。

分别说明候选的阅读路径、贡献位置、分组、通道、线路与文字安排；根据同一语义结构比较。主线通常直连或一折，多折必须说明避障/真实拓扑理由。端口居中或成组对称，不随机落点。

同类照片宽度统一，保持纵横比和重要内容，名称尺寸等与图像成组；标签一致。不放无意义外框、重复符号和装饰线。纯分组边框不能被误读成模块。

自评完成就继续，不默认向用户展示长篇中间状态或索要选稿批准。科学疑点另问，不能由视觉选优替代事实判断。
