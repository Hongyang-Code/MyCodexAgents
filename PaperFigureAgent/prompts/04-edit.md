# 编辑与持续反馈

先read原.drawio（支持压缩输入，输出未压缩），识别多页、对象ID、父子、端口、折点和素材；原生文件与截图重建分开。原始文件先备份。parse/inspect不改变原文件。

新反馈写require并记录supersedes，确定最小变更对象和必须保护区域。定位目标后读取当前源哈希，patch要求expected-hash，拒绝过期基准。写新输出文件，不覆盖原稿。支持label/move/reconnect/style，更多变更可在当前XML副本中精确修改并保留未知元素、元数据和无关页。

模块文字与边文字写value；移动group保持子对象相对坐标；连接source/target始终保留。复杂折线移动端点后仍须检查旧控制点，必要时只重规划关联边，不能重排全图。若图谱中的标签或关系被用户改变，同步更新语义基准与证据，保持稳定ID。

diff核对添加、删除、修改对象，特别检查未授权对象/其他页面零变化。除XML序列化形式外，用户数据、对象、素材、布局和元数据应保持。复杂第三方组件不能可靠解析时保留原件并标限制。

复查当前与全部仍有效的历史要求。重新build造成旧布局恢复、旧要求覆盖新要求、任务A内容混入B均为失败。恢复任务用resume和最新当前文件；revisions为不可变快照，不自动回滚。
