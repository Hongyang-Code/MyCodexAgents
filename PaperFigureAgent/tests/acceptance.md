自动测试：`python -m unittest discover -s tests -v`。真实原生渲染：`python examples/run_examples.py --output outputs/新的目录 --render`。不得使用旧审查记录为新图背书。

| 输入类型 | 操作与预期 |
|---|---|
| 一句话 | examples/cases.py分支案例；自动建task，不向用户索要JSON |
| 截图而无论文 | 只向宿主提供一张示例PNG，不读其图谱，重建可辨节点及边；关键模糊项明确说明 |
| 零散材料 | “输入传感器读数”；后补“先去噪”；再补“阈值判别，无回归输出”；合并有效要求 |
| 连续纠正 | “表征融合”改为“特征融合”；保留ID，更新语义基准和原话历史 |
| 局部编辑 | 改标签/移动组/修改旁路，仅目标对象或必要关联边变化；其他页完全保留 |
| 未指定尺寸 | brief默认180mm，按导出边界检查印刷字号 |
| 科学缺口 | “带反馈，但未指定反馈端点”；具体问来源和目标，unresolved不得清空冒充通过 |
| 切换任务 | A和B使用独立目录；无科学模块、数据、作者要求及坐标串入 |

故障注入覆盖：遗漏/倒转/多余科学关系，非法引用、重复ID、父子循环、非法端口、越组、穿框穿字、标签冲突、不明确交叉、冗余折点、整图位图冒充、错误素材、过小字号、旧要求回退、旧文件/预览/审查基准、缺审、超轮数。
