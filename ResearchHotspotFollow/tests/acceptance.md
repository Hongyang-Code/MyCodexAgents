# 人工内容与流程验收

全部示例为合成情形，不表示真实论文结论。程序测试仅验证格式。

| 情形 | 预期行为 |
| --- | --- |
| 用户指定图像配准，历史为NLP | 本次采用图像配准，不混入历史领域。 |
| 当前仅有一篇配准论文，未指定领域 | 可暂定图像配准并标明依据，不自定医学范围；多个同等可能领域才澄清。 |
| 无可访问上下文 | 问研究领域，不猜测或声称记得旧任务。 |
| arXiv v1上月，v2本周仅排版变化 | 不算新论文，不以updated日期误纳入。 |
| 旧预印本本周正式发表 | 一条，标正式发表及旧v1，不称全新工作。 |
| 同文跨arXiv分类和期刊 | DOI/ID/作者与版本核对后合并，保留全部链接别名。 |
| 会议本周举行，论文两月前公开 | 不因会议日期纳入本周新论文。 |
| 日期只有数据库入库日 | 待核查，不当首次公开。 |
| 只有摘要但作者称SOTA | 作者报告归属、已读范围、可靠性不足；不能写实验公平或复现成功。 |
| 未开源但证据清楚 | 不自动判不可靠或略读。 |
| 高等级venue但贡献不清楚 | 不自动精读；记录需要核查的贡献。 |
| 仅低引用的新论文 | 不当作低价值；新近不等于已形成热点。 |
| “首次”缺前作比较 | 改为作者主张或明确优先性未核查。 |
| 理论/综述/数据集 | 按证明条件、检索方法、采样标注等评估，不硬填实验指标。 |
| 稿件本身缺结果 | 调用方核查补充或写明确缺口，TextReadable不得编造。 |
| 通过后删掉可靠性或整条论文 | 两个格式脚本拒绝对应结构缺失，审校状态失效。 |
| 一篇多个字段挤在同一段 | 拆成独立论文标题、基本信息段和七个分行列表项；保留限定和全部字段。 |
| 某组无符合项 | 明确未检出与覆盖范围，不凑数。 |
| 两次审校批次仍不通过 | 停止并报告未决事项，不通过新基准无限重启。 |

| HF本周收录上月论文，未有实质更新 | 排除，不以收录日代替首次公开日。 |
| 同文在期刊会议、HF、arXiv | 仅保留一条，按期刊会议 > HF > arXiv > 其他归组，保留全部渠道。 |
| 无热度的相关新论文 | 正常评估纳入，不设热度门槛。 |

| arXiv v1本周，但PDF和机构记录显示去年已发表 | 不当首次公开；只有核实实质变化才纳入更新。 |
| 更正本周发表，但仅更改作者拼写 | 不当实质研究更新；保留正确元数据。 |
| HF日期入口跳转旧日期 | 标记覆盖缺口，不把旧页面当作本周列表。 |

## 核心与相关领域扩展

| 情形 | 预期行为 |
| --- | --- |
| 用户只给核心领域 | 默认选择有明确技术联系的相关方向，说明依据，同一时间窗口四线扫描。 |
| 用户要求仅核心或排除某方向 | 关闭或限制扩展，报告首部说明，不被默认设置覆盖。 |
| 相邻论文仅同用热门架构 | 无具体联系不纳入正文；记录排除理由。 |
| 原任务实验充分，未在核心任务验证 | 论文可靠性与迁移证据分开；标待验证设想、智能体分析、条件、障碍及最小验证思路。 |
| 明确在核心任务验证的跨领域方法 | 直接解决核心任务时归核心；局部验证不外推到所有数据与条件。 |
| 同文多个技术联系或多个发现渠道 | 只保留一条正文，记录全部关系和发现渠道。 |
| 关联依据是旧经典文献 | 作为背景引用，不计入本期新论文。 |
| 润色将可能迁移改为已验证有效 | 语义审校失败，回到冻结文本修正；结构通过不能放行。 |
| 相关方向未检出或入口不可访问 | 分别说明实际扫描范围与缺口，不强求条数或声称不存在。 |
| 新字段或关联条件被删 | 本地检查器与展开的TextReadable契约阻止交付。 |
