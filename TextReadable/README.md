# TextReadable

在保留最初输入完整语义的前提下，检查并改善可读性和用语严谨性。默认最多修改3轮；达标即停止，失败如实返回。

## 直接使用

在当前任务中发送：

> 请先读取 E:\MyCodexAgents\TextReadable\AGENTS.md，按完整流程审校下面的文本。保持第一版原意，最多修改3轮。原文：……

也可将本目录作为工作目录。提供原文即可；读者背景、文体和保护片段按需补充。默认对话输出，不自动保存副本。

## 供其他智能体复用

调用方显式读取 AGENTS.md、workflow.md、checklist.md、interface.md，在当前任务中执行流程，取回最终正文和状态。无需创建新的任务或子智能体。相邻目录的指令不能假定自动加载；目录加载机制见 [OpenAI 官方说明](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。

PaperReader 的质量检测 B 阶段已接入此流程。论文事实核查、图像检查与全文一致性仍由 PaperReader 负责。出现必须改变原意的问题时返回事实核查阶段处理，再明确新基准复查。

## 核心取舍

- 每轮回到第一版，防止连续改写造成语义漂移。
- 提高清晰度，不删信息、不补知识、不改变结论强度。
- 原文已经清楚则不改；没有句长硬指标或主观总分。
- 原文过强、矛盾或歧义可能无法同时满足保真与严谨；返回问题，不自动改意。
- 3轮是指令约束，首版没有独立程序强制计数。检查是当前智能体自检，不能保证任意文本严格语义等价。

文件：AGENTS.md 为入口；workflow.md 定义循环；checklist.md 定义门槛；interface.md 定义复用协议；tests/acceptance.md 为人工语义挑战。

输入与输出只在用户明确要求时保存，放在 inputs/、outputs/ 或调用方指定产物目录。仓库仅保存配置与合成验收样例，真实输入、改稿、缓存不提交。

## 可选内容与格式要求

可在文本之外传入 output_requirements，包含内容责任与格式约束；只传文本仍按原流程审校。协议和示例见 requirements.md。PaperReader、NewsChaser 必须传入各自 text-readable-requirements.md 展开的具体要求。

缺少原始内容时退回调用方核查；已有内容仅需重排时可以修改。结构脚本提供可重复的栏目检查，实质覆盖与保真仍需审阅，不能保证任意文本的语义正确。
