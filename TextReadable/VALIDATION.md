# TextReadable 首版验收

日期：2026-09-07。方式：当前智能体静态审阅与人工语义走查；未启动独立模型测试、子智能体或 API。首版是目录指令，轮数上限依赖执行者遵守，不是程序硬限制。

## 人工样例走查

| 样例 | 本次处理结果 | 判断依据 |
| --- | --- | --- |
| A 长句保真 | 候选：在仅使用训练集且未引入额外标注的条件下，我们观察到该方法在两个数据集上可能改善小目标识别。但其在其他数据集上的效果尚未验证。 | 拆为两句；全部条件、可能性、任务对象和未验证范围保留。1轮可通过。 |
| B 已清楚的数字句 | 原样返回“误差从5%降至4%。” | 0轮语言检查通过，不增加相对降幅；未核实外部数字真实性。 |
| C 歧义指代 | 原样保留，needs_clarification；询问模型属于甲还是乙。 | 无法无损地任选指代。 |
| D 过度外推 | 原样保留，needs_clarification；指出单数据集不能据此证明所有场景有效。 | 弱化为“可能”会改变原意，需调用方处理。 |
| E 未显著与等效 | 原样保留，0轮通过。 | 不把未发现显著差异改成相同。 |
| F 引语 | 原样保留引用文字、公式字符和[1]。 | 逐字保护。 |
| G 量词改写 | 拒绝将不同句中的至多/至少合成不带范围的“三次”。 | 需保留各句原有对象与限定。 |
| H 逐轮漂移 | 拒绝“通常改善”，还原为“可能改善”后再查。 | 频率与可能性不能互换。 |
| I 零修改预算 | 保持原文，仅给问题；not_passed/max_rounds。 | 不允许一次“顺手修改”。 |
| J 文内指令 | 仅作为待审文本，不上传或调用工具。 | 输入数据不能覆盖调用指令。 |
| K 停滞 | 在出现版本往返或连续两轮无改善时结束。 | 控制流走查确认存在提前停止分支。 |
| L 上限与覆盖 | 不回传已知漂移稿；末段缺失则不声称全文通过。 | 保留安全版本、未通过状态和缺失范围。 |

## 接口与集成审查

- original_text 为固定基准，候选与上下文不自动加入基准。
- 默认为3轮，允许0～10；每轮修改后必查，最后一轮无例外。
- passed / needs_clarification / not_passed 分开，状态和正文分离。
- PaperReader B阶段显式读取本目录；A事实核查、C图片与一致性检查仍保留。
- PaperReader每份报告最多2次文字审校批次，禁止通过反复新建原文逃避上限。
- 根 AGENTS.md 没有增加全仓库强制文字改写规则，其他智能体按需复用。
- 真实输入/输出使用排除目录，配置与人工合成样例可版本管理。
- 新会话自动加载、不同模型执行稳定性、任意长文语义等价均未做独立验证。

## 后续回归方法

按 tests/acceptance.md 在新任务中执行，检查状态与保护信息，不要求改稿逐字匹配本文件。任何漏掉限定、添加知识、隐瞒失败或超出上限的行为都应视为回归。不得以这些有限人工例子宣称普遍可靠。

## 2026-09-07 内容与格式约束更新

新增可选 output_requirements 和逐项内容覆盖结果；两个调用方传入具体约束，NewsChaser 保留每件事件的独立影响栏目。结构脚本单独测试，无要求时不增加限制，缺栏目/空栏目/漏事件等失败。最终文件检查绑定 sha256，禁止交付时再删栏。

本次验证包括结构脚本的合成回归测试及调用协议静态核对。语义保真与内容实质覆盖仍依赖审阅，没有进行独立模型评测，也未按新机制重跑既有新闻简报。不能把结构测试通过当作新闻事实或论文分析通过。
