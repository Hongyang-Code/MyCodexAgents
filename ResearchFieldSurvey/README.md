# ResearchFieldSurvey

寻找一个领域的主干论文，整理问题、方法路线和发展脉络。默认跨历史检索，至少20篇去重后的合格论文，不设上限；以方法论文为主体，少量骨干综述须说明奠基作用。

## 使用

> 请读取 E:\MyCodexAgents\ResearchFieldSurvey\AGENTS.md，调研“图像配准”的主干论文。重点理解主要方法路线及演进，至少20篇，优先方法论文。

可补充子方向、已有基础、年代或排除主题。缺省领域可根据可访问上下文推定并说明依据；不会默认沿用验收示例作为长期偏好。

输出包含领域全景、发展脉络、方法路线比较、逐篇分行概述、阅读路线及未决问题。每篇提供发表简称和CCF等级/状态、可靠性边界与阅读建议。最后执行TextReadable，传入完整内容与格式契约。

与ResearchHotspotFollow的区别：本智能体建立跨年代领域知识框架；前者发现近一周新论文。默认不调用PaperReader，不运行实验，也不自动提交推送。

材料不足20篇时报告明确未完成并列证据缺口，不能为达标凑数。结构测试不证明选文代表性或科研判断正确。运行 `python -m unittest discover -s ResearchFieldSurvey/tests -p "test_*.py" -v` 验证结构门槛。
