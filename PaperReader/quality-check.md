# 独立质量检测：必须在交付前完成

本文件是交付门槛，不是可选建议。同一智能体从读者和审稿人的视角单独审校初稿。禁止将“已生成报告”视为“已完成核查”。

## A. 事实与证据

- 回到原文/外部来源核对全部核心结论、关键数字、公式和引用位置。
- 核对年份与版本、作者和 venue，检查引用链接是否实际对应声称的内容。
- 重算关键提升，区分百分点与百分比，检查单位、指标方向、验证/测试、单模型/集成。
- 检查额外数据、训练和测试预算；条件不同不能直接比较。
- “首次”“奠基”“显著”“证明”“普遍”等强断言需要相称证据；否则改成准确的有限结论。
- 区分作者主张、核实的原文内容、独立结果和分析；不能把相关性改写成因果。
- 未读全文不宣称全文核查；未运行不宣称复现；未检查后作引用表不声称引用关系。

## B. 解释与可读性

- 读者能顺着理解问题、方法、证据、结论及边界，不必反复寻找术语和指代。
- 主体为简体中文。保留原文的术语有必要性，首次出现解释中文含义。
- 一句话尽量只承担一个主要判断，一段围绕一个意思；先结论后依据。
- 拆分长难句，删空泛评价和重复；消除“这/其/该”指代不清与跳步。
- 必要术语、符号和假设有解释，保留影响理解的推导。
- 短句不能删掉限定条件，也不能成为互不衔接的碎片。
- 摘要写概括，不能把压缩摘要标成完整翻译。模板无空占位符。

## C. 一致性与视觉

- 摘要、正文、可靠性表、建议、来源记录和导图中的数字、术语、结论一致。
- 导图符合实际章节，节点压缩后仍保留关键限定；实际打开 PNG 检查字形、字号、重叠和裁切。
- Markdown 标题、表格、公式、引用便于阅读。图文件存在且能打开，图源码不替代图片交付。

## D. 修改、复查与交付判定

记录简短可核查审校结果：问题 → 修正 → 依据 → 复查结果。发现错误先改，再复查所有受影响内容。数字/结论修改后重新查来源和全文一致性；图修改后重新查看。

以下问题必须修正后才能交付完整报告：已发现的事实错误、无依据断言、关键逻辑缺口、重要数值不一致、影响阅读的排版错误。

外部材料缺失无法解决时，可交付有明确范围的部分结果，列出缺失、影响和下一步验证。无法生成或查看合格导图时，说明图片未完成，不能宣称四项交付全部通过。不能无限重写等待不可能的确定性，也不能把未完成写成通过。

最终给修订后的正文和必要未决事项，不把审校流水账塞进报告。自检不等于独立复现、独立审稿或正确性保证。
