# 地区与领域分类

标签为检索和浏览用途，不代表政治立场、法律认定或主权判断。原文地点使用可核实名称，争议称谓须说明来源；不由分类推导政治结论。

## 地区

全球／跨地区、中国、东亚其他地区、东南亚、南亚、中亚、西亚／中东、欧洲、北美、拉美与加勒比、非洲、大洋洲。

具体报道保留精确地点，不以分类标签作出有争议的地域归属认定。东亚其他地区包含日本、韩国、朝鲜、蒙古；北美在本分类指美国、加拿大及格陵兰，墨西哥归拉美与加勒比。俄罗斯跨洲事件按具体地点或跨地区标记，不强行只属一洲。跨地区标签不能替代已知具体涉及地区。

每件事件分别记录发生地、直接相关地区、已证实受影响地区，可含多个。影响未知不能靠推测扩展标签。

## 领域

| 主领域 | 典型内容 |
| --- | --- |
| 政治与公共治理 | 选举、法律、公共政策、行政决策 |
| 国际关系与安全 | 外交、冲突、国际协定、安全事务 |
| 经济与金融 | 宏观数据、货币财政、金融体系 |
| 产业与商业 | 企业活动、行业政策、贸易与供应链 |
| 科技与科研 | 技术发布、科学发现、航天与研究活动 |
| 社会与民生 | 教育、就业、公共服务、灾害救援与生活事件 |
| 医疗与公共卫生 | 疫情、卫生政策、药械、公共卫生进展 |
| 环境与能源 | 气候、污染、生态、能源供给与政策 |
| 文化与体育 | 文化活动、文化遗产、体育赛事 |

每件设置一个主要领域，可附关联领域。以本期新增事实的主要内容选主领域，歧义通过关联标签解决，不重复正文。没有相关事件可为空，不凑分类配额。

## 覆盖记录

sources.md按地区和领域各列一份扫描表：查询/入口、获得线索、已纳入事件ID、排除原因或缺口。允许组合检索，不必把所有地区×领域组合逐格检索，但不能只查少量熟悉主题后声称全球覆盖。
