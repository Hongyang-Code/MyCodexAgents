# 专业审稿维度

按论文类型、阶段和提供范围选用，非适用项说明理由，不强填实验栏，不设置质疑数量配额。

| 维度 | 核心检查 |
| --- | --- |
| 问题与贡献 | 问题是否明确且有意义？缺口是否被证据支持？贡献与实际方法/实验是否对应？ |
| 创新点与前作 | 作者声称与已核实差异分开。检查最接近方法及更简单替代，不编首次或不存在的前作。 |
| 方法与理论 | 输入输出、定义、符号、算法流程和成立假设是否完整？关键推导有无缺口？理论范围是否被实验或摘要夸大？ |
| 实验有效性 | 数据拆分、样本独立性、泄漏、调参、资源预算和协议是否公平？关键baseline和消融是否回答假设？ |
| 指标与统计 | 指标是否适合主张、方向和单位是否正确？均值差异是否被过度解释？显著性、效应量、重复实验或不确定性是否足够？不编p值。 |
| 解释与外推 | 相关是否被当因果？是否有替代解释或混杂？局限、失败案例和适用边界是否匹配结论？ |
| 复现条件 | 实现、超参数、数据与评估是否足够说明？开源有无实际检查？不将未运行写成复现。 |
| 表达与结构 | 主干是否清楚？术语、公式、图表和叙述是否一致？多余复杂语言是否增加理解负担？ |

理论论文优先假设、证明正确性及边界；方法论文优先机制、对比与验证；应用论文核查实际任务、代表性及评价；综述核查检索与综合方法。只有段落时不因未附实验细节推断作者未做。

严重性与确定性分开：critical/major/minor表示若成立的影响，成立/部分成立/不成立/证据不足表示裁决。不要用“很严重”代替证据，也不要因可读性好掩盖研究缺口。
