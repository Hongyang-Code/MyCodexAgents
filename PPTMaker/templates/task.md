# 任务需求与状态

- 模式：template / materials / topic；材料各自用途：
- 主题与呈现目标：
- 听众与知识背景：明确输入或推定依据
- 严格审查角色、最高专业水平和依据：限定于该听众和场景
- 严格审查状态、问题处置及复查版本：
- 严格审查修订轮数：最多3轮，不重置文字与视觉预算
- 用途：现场讲述 / 独立阅读
- 语言：简体中文（原题、术语等按需保留）
- 时长与总页数：含封面、目录、附录；冲突处理
- 必保留内容及应在页面/备注的位置：
- 模板、固定元素、允许修改范围：
- 风格参考/模板、实际查看页码与采用依据：
- 风格美观度审查：逐页六维度、整套三维度、问题闭环及最终版本（见visual-reference-review.md）
- 用户风格反馈：pending / accepted / rejected；记录真实依据，不能用内部审查代替
- 是否允许联网及调研范围：
- 协作方式：样页确认 / 直接完成（记录授权原话）
- 原始文件、版本与哈希：
- 来源、缺口与不确定性：
- 状态：准备 / 等待样页确认 / 制作 / 复查 / 合格 / 有限制草稿
- TextReadable批次和修改轮数：总计不超过2批，每批最多3轮
- 视觉修改轮数：不超过3轮
- 目标应用实际检查：未运行 / 已运行，具体结果

编辑任务保存changes.md：原页面/对象、修改前后、修改方式、原因、含义影响。不要覆盖用户原稿。
