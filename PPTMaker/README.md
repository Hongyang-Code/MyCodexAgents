# PPTMaker

支持按模板制作、给材料重组、给主题调研三种模式。默认科研汇报，先给逐页方案及2～3张代表页，确认后完成整套；也可明确要求直接完成。文字精练、视觉克制，新制对象可编辑，成品图片可以直接使用。

## 使用模板

> 请读取 E:\MyCodexAgents\PPTMaker\AGENTS.md 及其要求文件。根据【材料路径或主题】制作PPT，用于【组会/答辩/其他场景】，听众是【知识背景】，目标是【希望理解或讨论的问题】。汇报【时长】，总共【页数，可省略】页。模板为【路径，可省略】，必须保留【内容/固定元素】。先给逐页方案和代表页，再完成整套。

给定主题时补充允许检索的范围；若希望一次完成，将末句改为“直接完成整套并审核，无需中途确认”。已有PPT仅美化时明确“保留内容，只调整版式”。图片作为成品使用，无需另行申请豁免。

## 交付与限制

风格美观度审查内置于所有任务，无须每次提示。逐页检查构图、层级、配色、字体、图文关系与视觉对齐，整套检查一致性、节奏和参考适配；记录实际参考、问题修复及最终版本。明确缺陷未解决不能交付，修复计入原视觉预算。技术通过不等于美观通过，内部审查不等于用户认可。详见visual-reference-review.md。

输出前内置严格听众审查，按目标听众中可能遇到的最高专业水平核对证据、论证、比较条件、表达与呈现目标。未通过先修改或返工再复查；达到修订上限或缺少证据时只报告阻塞，不主动交付未通过PPT。详见audience-review.md。模拟审查通过不等于真实专家认可。

交付可编辑PPTX、预览及必要限制，备注包含讲解与来源。编辑旧稿附逐页修改说明。原稿保留，真实材料与产物仅存本地，不自动Git同步。

内置TextReadable及逐页内容、格式契约，最多2批/每批3轮；视觉最多3轮。每页最终渲染并查看，不能只跑结构检查。数据、事实、逻辑和视觉判断都需当前任务审核，自动检查不能代替。未在PowerPoint打开不会宣称已验证其显示效果。

实现依赖当前可用Presentations技能与配套运行时；每次动态定位。缺工具如实返回限制，不能改用整页图片冒充可编辑内容。检查接口见scripts/README.md，验收状态见VALIDATION.md。
